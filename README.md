# wazam.ai

The website for WAZAM, served by GitHub Pages at https://wazam.ai: the home page, the privacy policy, the terms of service and a 404 page. The 404 page uses root-relative paths (`/brand/...`) because GitHub Pages serves it for missing URLs at any depth; every other page uses relative paths. The old address, https://ogmxra.github.io/, redirects there.

WAZAM identifies birds and insects by sound.
